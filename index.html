Panduan Sambungan Kabel & Tethering

Cara menghubungkan kamera fisik agar terbaca di browser.

1. Menggunakan Kamera Smartphone (Android/iPhone) Sambungkan HP menggunakan kabel data USB ke komputer. Gunakan mode Webcam / PTP atau aplikasi seperti DroidCam / iVCam. Kamera HP otomatis muncul di pilihan sumber video.
2. Menggunakan Kamera DSLR (Canon/Nikon) Gunakan kabel USB tethering atau HDMI capture card. Pastikan software tethering pabrikan aktif atau browser mendeteksi perangkat video eksternal.
